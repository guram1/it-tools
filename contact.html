Helpful Tips for Bug Reports

To help us resolve issues faster, please include:

  • Tool name — Which tool you were using (e.g., Subnet Calculator, DNS Lookup)
  • Browser and version — Chrome 120, Firefox 121, Safari 17, etc.
  • Steps to reproduce — What you entered and what you clicked
  • Expected vs. actual result — What you expected to happen vs. what actually happened
  • Screenshots — A screenshot of the error or unexpected behavior helps tremendously
